# API 명세 — 사내 도서 대여 POC

[design.md](design.md) 3절을 API 하나씩 풀어 쓴 명세다.

## 공통

- 기본 경로: `/api`. 서버는 3000 포트에서 돌고, 화면(5173)은 Vite proxy 로 `/api` 를 서버에 넘긴다.
- 요청과 응답은 JSON 이다(`Content-Type: application/json`).
- 오류 응답은 모두 같은 형식이다.

  ```json
  { "error": "메시지" }
  ```

- 검사 순서: 이름(400) → 책 존재(404) → 대여 상태(409). 여러 조건에 걸리면 앞의 오류 하나만 돌려준다.

### 책 객체

세 API 는 모두 아래 형식의 책 객체를 돌려준다.

| 칸 | 타입 | 설명 |
|---|---|---|
| `id` | number | 책 id |
| `title` | string | 제목 |
| `author` | string | 저자 |
| `borrower` | string \| null | 대여자 이름. `null` 이면 대여 가능 |
| `borrowed_at` | string \| null | 대여 시각(ISO 8601). 대여 가능이면 `null` |
| `due_date` | string \| null | 반납 예정일(YYYY-MM-DD). 대여일 + 14일. 대여 가능이면 `null` |

- 상태 칸은 따로 없다. `borrower` 가 `null` 이면 「대여 가능」, 아니면 「대여 중」 이다.

### 오류 메시지 모음

| 상태 | 메시지 | 쓰는 API |
|---|---|---|
| 400 | `이름을 입력하세요.` | 대여 |
| 404 | `책을 찾을 수 없습니다.` | 대여 · 반납 |
| 409 | `이미 대여 중인 책입니다.` | 대여 |
| 409 | `대여 중인 책이 아닙니다.` | 반납 |

## 1. `GET /api/books` — 책 목록

책 전체를 id 순서로 돌려준다.

| 항목 | 내용 |
|---|---|
| 경로 변수 | 없음 |
| 요청 본문 | 없음 |

### 응답

| 상태 | 언제 | 본문 |
|---|---|---|
| 200 | 항상 | 책 객체 배열(id 순서) |

200 예시

```json
[
  {
    "id": 1,
    "title": "클린 코드",
    "author": "로버트 C. 마틴",
    "borrower": "김지인",
    "borrowed_at": "2026-10-30T09:00:00.000Z",
    "due_date": "2026-11-13"
  },
  {
    "id": 2,
    "title": "리팩터링",
    "author": "마틴 파울러",
    "borrower": null,
    "borrowed_at": null,
    "due_date": null
  }
]
```

---

## 2. `POST /api/books/:id/borrow` — 대여

대여 가능한 책을 빌린다. 서버가 `borrowed_at` 에 지금 시각, `due_date` 에 대여일 + 14일을 채운다.

| 항목 | 내용 |
|---|---|
| 경로 변수 | `id` — 빌릴 책 id |
| 요청 본문 | `{ "name": "김지인" }` |

요청 본문

| 칸 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `name` | string | 예 | 대여자 이름. 앞뒤 공백을 지우고 저장한다. 비었거나 공백뿐이면 400 |

### 응답

| 상태 | 언제 | 본문 |
|---|---|---|
| 200 | 대여 성공 | 바뀐 책 객체 1개 |
| 400 | `name` 이 없거나 공백뿐 | `{ "error": "이름을 입력하세요." }` |
| 404 | 없는 책 id | `{ "error": "책을 찾을 수 없습니다." }` |
| 409 | 이미 대여 중인 책 | `{ "error": "이미 대여 중인 책입니다." }` |

200 예시

```json
{
  "id": 1,
  "title": "클린 코드",
  "author": "로버트 C. 마틴",
  "borrower": "김지인",
  "borrowed_at": "2026-10-30T09:00:00.000Z",
  "due_date": "2026-11-13"
}
```

- 409 로 거부되면 그 책의 `borrower` · `borrowed_at` · `due_date` 는 바뀌지 않는다.

## 3. `POST /api/books/:id/return` — 반납

대여 중인 책을 반납한다. 누구나 반납할 수 있다(대여자 확인 없음).

| 항목 | 내용 |
|---|---|
| 경로 변수 | `id` — 반납할 책 id |
| 요청 본문 | 없음 |

### 응답

| 상태 | 언제 | 본문 |
|---|---|---|
| 200 | 반납 성공 | 바뀐 책 객체 1개(`borrower` · `borrowed_at` · `due_date` 가 `null`) |
| 404 | 없는 책 id | `{ "error": "책을 찾을 수 없습니다." }` |
| 409 | 대여 중이 아닌 책 | `{ "error": "대여 중인 책이 아닙니다." }` |

200 예시

```json
{
  "id": 1,
  "title": "클린 코드",
  "author": "로버트 C. 마틴",
  "borrower": null,
  "borrowed_at": null,
  "due_date": null
}
```

- 반납한 책은 다시 대여할 수 있다.
